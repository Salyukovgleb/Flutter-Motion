# kinetic_motion

Flutter-слой Flutter Motion с входом `.motion()` и нулевой настройкой.

Сейчас подготовлен только каркас пакета (шаг 1). Публичные анимационные символы
ещё не реализованы, пакет не опубликован. Шаблонный демонстрационный API удалён.

Требования: Flutter 3.41.2 / Dart 3.11.0 для разработки общего workspace.
